# தமிழக வெற்றிக் கழகம் (TVK) - மணவை சட்டமன்றத் தொகுதி
## மக்கள் நல இணையதளங்கள் அதிகாரப்பூர்வ தொடக்க விழா (Grand Web Launch Portal)

மாண்புமிகு தமிழ்நாடு முதலமைச்சர் **தளபதி விஜய்** மற்றும் மாண்புமிகு நீர்வளத்துறை அமைச்சர் **என். ஆனந்த் (புஸ்ஸி ஆனந்த்)** அவர்களின் வழிகாட்டுதலில், மணவை சட்டமன்ற உறுப்பினர் **இரா. கதிரவன்** அவர்களின் முன்னெடுப்பில் உருவாக்கப்பட்ட **nammakathiravan.org** மற்றும் **manavaimla.com** தளங்களின் தொடக்க விழா இணையதளம்.

---

### முக்கிய அம்சங்கள் (Key Highlights)

1. **முகப்பு அரங்கம் (Clean & Impactful Home Page)**:
   - எந்தவித தேவையில்லாத நீண்ட பத்திகளும் இன்றி, கண்ணை கவரும் அழகிய எளிய வடிவமைப்பு.
   - முகப்பிலேயே 3 முக்கிய தலைவர்களின் படங்கள் மற்றும் பதவிகள்:
     1. **மாண்புமிகு தமிழ்நாடு முதலமைச்சர் தளபதி விஜய்** (CM Thalapathy Vijay)
     2. **மாண்புமிகு நீர்வளத்துறை அமைச்சர் என். ஆனந்த்** (Minister N. Anand - Bussy Anand)
     3. **மணவை சட்டமன்ற உறுப்பினர் இரா. கதிரவன்** (Manavai MLA R. Kathiravan)
   - பிரம்மாண்ட **"இணையதளங்களை துவங்கி வைக்கவும் (LAUNCH NOW)"** பொத்தான்.
   - **முக்கியமானது:** முகப்பில் தளங்களின் இணைப்புகள் காட்டப்படாது; கவுண்ட்டவுன் முடிந்த பிறகே அதிகாரப்பூர்வமாக திறக்கப்படும்!

2. **10 வினாடி நேரடி கவுண்ட்டவுன் (Live Countdown Overlaid on Dynamic Vijay Photos)**:
   - கவுண்ட்டவுன் எண் மற்றும் சுழலும் ஒளி வளையம் (Circular Dial) **தளபதி விஜய் புகைப்படத்தின் மேல் நேரடியாக (Overlaid)** தோன்றும்.
   - ஒவ்வொரு வினாடிக்கும் (10, 9, 8... 1) தளபதி விஜயின் மாறுபட்ட கம்பீரமான புகைப்படங்கள் மற்றும் முழக்கங்கள் மாறும்.
   - ஒவ்வொரு வினாடிக்கும் **1.25 விநாடிகள் (1250ms)** கால இடைவெளி வைக்கப்பட்டுள்ளது.
   - Web Audio API மூலம் எலக்ட்ரானிக் டைமர் பீப் ஒலிகள் இயங்கும்.

3. **அதிகாரப்பூர்வ தொடக்க அரங்கம் (Post-Launch Reveal)**:
   - கவுண்ட்டவுன் 0-வை அடைந்ததும்:
     - பிரம்மாண்ட தங்க வண்ண வெடிகள் & காகித மழை (Celebration Confetti & Fireworks).
     - வெற்றிக் கொண்டாட்ட இசை (Trumpet Fanfare Chords).
     - **மட்டுமே 2 அதிகாரப்பூர்வ தளங்கள் காட்டப்படும்**:
       1. **nammakathiravan.org** - நம்ம கதிரவன் மக்கள் நலத் தளம்
       2. **manavaimla.com** - மணவை MLA தொகுதி சேவை தளம்
     - நேரடியாக இணையதளத்திற்கு செல்லும் பட்டன்கள், நேரடி QR Code ஸ்கேனர் மற்றும் இணைப்பு நகலெடுக்கும் வசதி.

4. **அதிநவீன தொழில்நுட்பம் (Modern Frontend Tech)**:
   - Pure HTML5, CSS3, Vanilla JavaScript (100% Client-Side, No External Backend Required).
   - 3D சில்க் கொடி அலைவு அனிமேஷன் (Canvas Silk Flag Wave).
   - நகரும் மேடை லேசர் ஒளிக்கதிர்கள் (Stage Laser Beams).
   - புரொஜக்டர் மற்றும் எல்.இ.டி திரைகளுக்கான முழுத்திரை வசதி (Fullscreen Projector Mode).
   - ஒலி ஆன்/ஆப் கட்டுப்பாடு (Sound Toggle).
   - தமிழ் / English இருமொழி மாற்றம் (Language Switcher).
   - வாட்ஸ்அப் நேரடி பகிர்வு (WhatsApp Share).

### இயக்குவது எப்படி? (How to Run Locally)

1. டெர்மினலில்:
   ```bash
   node server.js
   ```
2. உலாவியில் திறக்கவும்:
   ```
   http://localhost:3000/
   ```

### இணையத்தில் ஹோஸ்ட் செய்வது எப்படி? (Hosting Online)

- **GitHub Pages**
- **Vercel** (`vercel deploy`)
- **Netlify** (Drag and drop the folder)
- **Hostinger / cPanel / Shared Hosting** (Just upload files to `public_html`)
